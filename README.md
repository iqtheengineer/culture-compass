## 🌟 Overview

Culture Compass revolutionizes travel planning by gamifying cultural discovery. Inspired by collectible card games like Pokémon, this progressive web app transforms learning about countries into an addictive collection experience. Whether you're planning your next adventure or exploring from home, Culture Compass makes cultural education engaging and practical.

### 🎯 Key Value Propositions

- **🎮 Gamified Learning**: Turn cultural education into an engaging game
- **📱 Offline-First**: Download country data for use without internet
- **🗺️ Interactive Discovery**: Explore countries through an intuitive world map
- **📚 Comprehensive Data**: Essential travel information in digestible formats
- **🏆 Progress Tracking**: Visual achievement system with bronze, silver, and gold badges

## 🚀 Getting Started

### Quick Start (No Installation Required)

1. **Visit the Live Demo**: [https://iqtheengineer.github.io/culture-compass/](https://iqtheengineer.github.io/culture-compass/)
2. **Complete Onboarding**: Set up your profile and unlock your first card
3. **Start Collecting**: Explore the world map and collect countries
4. **Download for Offline**: Mark countries as downloaded for offline access

### Local Development

```bash
# Clone the repository
git clone https://github.com/iqtheengineer/culture-compass.git

# Navigate to project directory
cd culture-compass

# Option 1: Open directly in browser
open index.html

# Option 2: Use a local server (recommended)
python -m http.server 8000
# or
npx serve .

# Visit http://localhost:8000
```

### Installation as PWA

1. Visit the app in Chrome/Edge
2. Click the "Install" button in the address bar
3. Enjoy native app experience with offline support
